# Search, Filters & Productive Workflows

Trail includes instant server-side search, multi-faceted filtering, and dedicated smart views so team members can slice through hundreds of issues in seconds.

---

## 1. Fast Global Search

The search input in the ticket toolbar searches across multiple dimensions simultaneously:
- **By Ticket Reference Code:** Type `MKT-001` or `CP-12` to jump directly to an exact ticket.
- **By Ticket Number / ID:** Typing `105` matches ticket `#105`.
- **By Title & Description:** Matches any keyword or phrase within the issue text.
- **By People:** Search for author or assignee names (e.g., `Sarah Connor`).

> **Tip:** Hit <kbd>Enter</kbd> in the search box to immediately apply criteria and update the table.

---

## 2. Multi-Faceted Filter Toolbar

You can combine multiple criteria to isolate specific slices of work:

- **Project Filter:** Limit the view to a single workspace or browse across all projects.
- **Status Filter:** Select `New`, `In Progress`, `Waiting`, or `Blocked`.
- **Priority Filter:** Filter by `Urgent`, `High`, `Medium`, or `Low`.
- **Assignee Filter:** Filter by a specific person or select **"Unassigned Only"** to find tickets waiting to be picked up.
- **"Clear Filters" Button:** Instantly resets all parameters back to default with a single click.

---

## 3. Dedicated Smart Views

In the main navigation, Trail provides pre-filtered personal views:

| View | Purpose |
| :--- | :--- |
| **All Tickets** | Global master view across all workspaces. |
| **Assigned to Me** | Your personal active sprint to-do list. |
| **Created by Me** | Issues and bug reports you opened that you are waiting on others to resolve. |
| **Watched Tickets** | All issues you have explicitly subscribed to for updates. |

---

## 4. Sorting Columns

In project ticket tables, click any column header to sort on demand:
- Click once $\to$ **Ascending** ($\uparrow$)
- Click twice $\to$ **Descending** ($\downarrow$)
- Supported sort columns: `ID`, `Title`, `Status`, `Priority`, `Due Date`.
