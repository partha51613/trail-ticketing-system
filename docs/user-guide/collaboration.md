# Collaboration, Comments & Attachments

Trail provides a unified, real-time timeline for each ticket, keeping discussions, file uploads, and historical changes visible in one chronological stream.

---

## 1. Unified Timeline & Filter Pills

Inside every ticket page, the **Timeline** records both human conversations and system audit logs:

- **"All" Filter:** Shows the complete story—comments, status transitions, reassignments, and file additions.
- **"Comments" Filter:** Hides system events, showing only messages between team members.
- **"History" Filter:** Hides conversational comments, showing pure audit log diffs (who changed what, previous vs. new values, and exact timestamps).

---

## 2. Posting Comments & Markdown

You can leave status updates or ask questions in the comment editor at the top of the timeline:
- **Markdown Support:** Full support for bold (`**text**`), italics (`*text*`), bullet lists, inline code (` `var x` `), and block quotes.
- **Author Badge:** Comments posted by the original ticket creator automatically display an **Author** badge for quick identification.
- **Inline Editing:** Authors can hover over their own comments and click the pencil icon to edit typos or update text in-place.

---

## 3. File Attachments & Drag-and-Drop

Trail includes an integrated file management system:

### Supported Formats
- **Images:** PNG, JPEG, WebP, GIF.
- **Documents:** PDF, Word (`.doc`, `.docx`), Plain Text (`.txt`), CSV, Logs (`.log`), and ZIP archives (`.zip`).

### Upload Limits & Safety Checks
- **File Limit:** Up to 10 files per comment or ticket submission.
- **Size Limit:** Max **10MB per file**. If an oversized file is dropped, Trail alerts you with a modal dialogue before consuming bandwidth.

### Image Lightbox Viewer
Clicking on any image attachment in a ticket description or comment opens the **Trail Lightbox**:
- High-resolution, zero-clutter modal preview.
- **"Open" Button:** Opens the original full-size image in a new browser tab.
- **Fast Dismiss:** Click anywhere outside the image or press the <kbd>Esc</kbd> key to close instantly.

---

## 4. Watching Tickets & Notification Feed

Want to track an issue you didn't create?
- Click the **"Watch"** bell icon in the ticket header.
- As a watcher, you receive updates whenever comments are posted or status changes occur.
- View all issues you are monitoring anytime under **Tickets $\to$ Watched Tickets**.
